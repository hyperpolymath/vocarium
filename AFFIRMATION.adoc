== What this is, and how it works

A short, dated, signed snapshot of what hyperpolymath can honestly and verifiably
claim about *Vocarium* at one exact commit. Nothing here is marketing or a
promise; those live in the README. Every claim is tied to a command, and where a
command could not be run in the session that wrote this file it says so and names
the run that attests it instead. The anchor (<<verifiable-anchor>>) fixes commit,
time and toolchain. It is landed by a signed commit.

== The epistemic contract

Best belief at the timestamp below, not a guarantee of correctness; the only
guarantee is no intentional overclaim. Refute any line with a counter-example, a
failing run, or a contradicting source.

== What we affirm

[cols="2,1,3",options="header"]
|===
| Claim | Status | Evidence (command / file)

| The store engine `voc` (pure Zig, no C; ADR-0002) builds and its unit tests
pass under the pinned Zig 0.16.0.
| NOT RUN here — attested by CI
| `zig build test` (Zig 0.16.0, `.tool-versions`). The session that wrote this
file could not run Zig: ziglang.org and its mirrors were unreachable and a
checksummed conda-forge 0.16.0 binary was obtained but not permitted to execute.
CI runs it on every push: `.github/workflows/vocarium-ci.yml` (mlugg/setup-zig
pinned to 0.16.0). The run on this branch is cited in the Phase 0 pull request.

| The M1 invoke slice holds end to end: the canonical fixture ingests; the same
stored trope yields opposite tropecheck verdicts under two use-models
(`casual-note` → `p-sufficient`, `critical-paraphrase` → `p-insufficient` with
the witness edge named); an unwarranted edge is refused at the store door.
| NOT RUN here — attested by CI
| `TROPECHECK_BIN=<tropecheck-rs> bash tests/e2e/invoke_slice.sh` → expected
`GATE PASS: invoke slice proven (use-relativity + warrant door + unit tests)`.
Same CI workflow (`./tests/e2e/invoke_slice.sh`), which hard-fails on toolchain
absence or skew. Note: without `TROPECHECK_BIN` the script builds the checker at
its own pin `69221ad6`; with it set, the pin is bypassed. The pin predates the
spec v0.2 consolidation and is to be bumped once Phase 0 lands upstream (issue
filed, not changed here).

| The store format is append-only JSONL (`{"t":"trope"|"edge"|"use_model"|"warrant"}`)
replayed into in-memory indexes; the only external contract is Trope IR v0.2 over
process I/O, verified by `tropecheck`.
| affirmed (by reading)
| `src/store/`, `docs/decisions/0002-pure-zig-wire-boundary.adoc`; the schema
at `trope-checker/schemas/trope-ir.schema.json` is the trust boundary.
|===

== What we do NOT claim

* `evoke`, `convoke`, `transvoke`, `provoke`, `revoke` — not implemented.
* The M2 Hermeneia `StoreProvider` adapter — not implemented (wire, do not link).
* Haec ingestion — not implemented.
* `neighbours` / nearestness — `unsupported` by design; the retention order and the
  cross-kind algebra live in trope-checker and are never reimplemented here.
* Nothing about `voc` was executed in the session that wrote this file; the two
  NOT RUN rows above are exactly that.
