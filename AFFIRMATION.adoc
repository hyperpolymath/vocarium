== What this is, and how it works

A short, dated, signed snapshot of what hyperpolymath can honestly and verifiably
claim about *Vocarium* at one exact commit. Nothing here is marketing or a
promise; those live in the README. Every claim is tied to a command or, for a claim
affirmed by reading, to the named source files; where a command could not be run in
the session that wrote this file it says so and names the run that attests it
instead. The anchor (<<verifiable-anchor>>) fixes commit,
time and toolchain. It is to be landed by a signed commit — the owner signs on
landing.

== The epistemic contract

Best belief at the timestamp below, not a guarantee of correctness; the only
guarantee is no intentional overclaim. Refute any line with a counter-example, a
failing run, or a contradicting source.

== What we do NOT claim

* `evoke`, `convoke`, `transvoke`, `provoke`, `revoke` — not implemented.
* The M2 Hermeneia `StoreProvider` adapter — not implemented (wire, do not link).
* Haec ingestion — not implemented.
* `neighbours` / nearestness — `unsupported` by design; the retention order and the
  cross-kind algebra live in trope-checker and are never reimplemented here.
* Nothing about `voc` was executed in the session that wrote this file; the two
  NOT RUN rows above are exactly that.
