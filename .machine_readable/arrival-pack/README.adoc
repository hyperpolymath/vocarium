= Arrival pack

The generated region in `CLAUDE.md` is a view of `vocarium_chora.deed` and
`.machine_readable/descriptiles/STATE.deed`. `extract.sh` reads them through
`scripts/deed-field.sh`; `generate.sh` replaces the marked region while
preserving notes outside it, and `verify.sh` checks it for drift. The verifier
runs shell subprocesses and is not a pure Yard computation.

Run `just claude-md` to regenerate or `just validate-claude-md` to check.
